# Devoir 2 - Application React avec React Router

Application React utilisant `react-router-dom` pour la navigation côté client sans rechargement de page.

## Fonctionnalités

- Barre de navigation avec les liens : **Accueil**, **À propos**, **Contact**
- Trois pages : `Accueil`, `À propos`, `Contact`
- Navigation sans rechargement de page avec mise en évidence du lien actif
- Page **404** pour les routes inexistantes

## Installation et lancement

```bash
npm install
npm run dev
```
